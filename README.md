# MK Vision — React + JavaScript

Plain React + Vite + JavaScript project. No TypeScript.

## Run in VS Code

```bash
npm install
npm run dev
```

Open the local URL Vite gives you.

## Build

```bash
npm run build
```

## Google Sheets

Customer requests are NOT stored in localStorage.

The Contact form has a `googleAppsScriptUrl` setting in:

`src/config.js`

We will connect that to Google Sheets after the website is running correctly.
